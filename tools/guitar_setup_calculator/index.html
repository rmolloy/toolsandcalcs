Six-step setup

Choose a starting profile, then replace its defaults with the measurements you actually take.

01String lengthNut reference to saddle reference, per string.

Published unit mass is used when a string matches. Axial stiffness is estimated from construction unless you enter a measured value.

Used only when string lengths differ; the nut, frets, and saddle fan around this perpendicular fret.

02RadiusSimple, compound, or flat fingerboard.

Millimetres: 12 in = 304.8 mm.

03ReliefNeck curve, measured as a peak and fret.

Capo fret 1, hold the string at the last fret, and measure from fret top to string bottom at the selected fret.

04Action at bridgeCapo fret 1, then measure at fret 12.

Measure vertically from the top of fret 12 to the bottom of each outside string, with a capo at fret 1.

Additional open-string action readings
05Action at nutOpen-string clearance above fret 1.

Measure vertically from the top of fret 1 to the bottom of each open outside string. The calculator adds each string diameter so the string tops follow the selected radius.

06Review compensation and verify intonationUse the nut and saddle pattern, then verify the real instrument.

The calculated pattern is a starting cut reference. Check each fretted string with a strobe tuner before making an irreversible cut.
