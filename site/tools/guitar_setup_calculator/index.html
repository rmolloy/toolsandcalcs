Guitar Setup Calculator

Use this tool to turn the setup you measured into string-by-string nut height and compensation targets you can verify on the instrument.

The calculator keeps six setup decisions in order: string length, radius, relief, bridge action, nut action, and intonation. Each result stays tied to the physical string that produced it.

A setup can feel right and still pull selected fretted notes sharp. The calculation estimates how the measured string path changes tension, then shows where the nut and saddle witness points need to move.

  • Scale length for every physical string
  • String manufacturer, construction, and diameter
  • Simple, compound, or flat fingerboard radius
  • Relief and the fret where it was measured
  • Capoed action at fret 12 for the first and last strings
  • Open-string clearance above fret 1 for the first and last strings

Use the drawing as a starting cut pattern, then verify every string with a strobe tuner on the actual instrument before removing material.
